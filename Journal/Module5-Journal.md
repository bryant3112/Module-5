# Module 5 Journal - Bryant Torres

## What I learned
In these modules, I learned more about using GitHub to manage projects and work with changes. I learned how issues can be used to keep track of problems and tasks that need to be completed. I also learned how milestones can help organize issues and keep track of progress.
Another thing I learned was how branches and pull requests work. A pull request allows me to make changes in a branch and review those changes before adding them to the main branch. I also learned how review comments can be added to a pull request before the changes are merged.

## Difficulties I Had
One difficulty I had was understanding all the steps involved with branches and pull requests. At first, it was a little confusing knowing which branch I was working on and when I needed to merge the changes. Going through the exercises step by step helped me understand the process better.
I also had to practice using issues and milestones because there are several different options in GitHub. After practicing with them, it became easier to understand how they can help organize a project.

## Things I want to remember 

Some things I want to remember for future projects are:

- Create issues to keep track of tasks and problems
- Use milestones to organize and track progress
- Create a branch before making changes
- Use a pull request to review changes
- Review comments before merging
- Make sure I am merging into the correct branch

I think these GitHub tools will be useful for my future programming projects because they can help me stay organized and make it easier to work with other developers.
